This contains the waydroid binary and dependencies from AUR.

waydroid - https://aur.archlinux.org/packages/waydroid

python-gbinder - https://aur.archlinux.org/packages/python-gbinder

libgbinder - https://aur.archlinux.org/packages/libgbinder

libglibutil - https://aur.archlinux.org/packages/libglibutil

A16_packages - used by the Android 16 options (needs the aidl6 servicemanager protocol)

waydroid 1.6.3 - https://archlinux.org/packages/extra/any/waydroid/ (signature checked against the Arch packager key)

libgbinder 1.1.45, python-gbinder 1.3.1, libglibutil 1.0.81 - same builds as A14_packages. libgbinder 1.1.45 is the first release with aidl6

SHA256SUMS is checked by install_android16_packages before pacman -U
